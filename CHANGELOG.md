# Changelog

All notable changes to this project are listed here.

## [1.1.0] - 2026-11-21

### Added
- Paste support: Ctrl+V, Cmd+V and Shift+Insert work on unlocked sites that block them.
- Alt+Shift+V (Control+Shift+V on Mac) shortcut that pastes clipboard text into the focused field, even where Ctrl+V is blocked.
- Green ON badge on the toolbar icon for sites where the extension is active.
- Popup shows the paste shortcut Chrome assigned, with a button to change it.

### Fixed
- Clipboard shortcuts now also work on non-Latin keyboard layouts.

## [1.0.0] - 2026-11-21

### Added
- Unlock text selection, right-click, copy and cut on sites that block them.
- Per-site and all-sites switches in the toolbar popup.
- JKING logo and credits.
